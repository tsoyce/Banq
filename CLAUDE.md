# Правила работы с репозиторием (для людей и ИИ-агентов)

Проект: TSOY.IN · Banq — портал о банках Казахстана. Общение и документация — по-русски.

1. Перед работой прочитай `docs/PLAN.md` (этапы, модель данных) и `docs/REGISTRY.md` (карта кода).
2. Каждый шаг записывай в `docs/JOURNAL.md` следующим номером `A..` (смотри последний номер в файле) и ставь этот номер в комментарий у созданного кода.
3. Новый модуль / таблица / переменная `.env` / настройка / маршрут → обнови `docs/REGISTRY.md` в том же PR.
4. Стек: PHP 8.3, Laravel 13, Blade + Tailwind 4 + Alpine. Без SPA и тяжёлых фреймворков на фронте без нужды.
5. Ставки не перезаписываются: новая ставка закрывает старую (`valid_to`).
6. После правок фронтенда — `npm run build` и коммит `public/build` (на сервере нет Node).
7. Тесты: `php artisan test`. Импорт Excel проверяется на `tests/fixtures/deposits-matrix.xlsx`.
8. Боевой сервер: BrainyCP, `/home/tsoy/sites/banqofbank`. Деплой — автоматически после слияния в `main` и зелёных тестов (A35, `docs/DEPLOY.md`); руками — `bash deploy.sh` на сервере.
