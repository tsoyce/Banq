# TSOY.IN · Banq of Bank — план проекта

> Живой документ. Меняется вместе с проектом. История решений — в [JOURNAL.md](JOURNAL.md), карта кода — в [REGISTRY.md](REGISTRY.md).

## 1. Цель

Портал о банках Казахстана: продукты, ставки, рейтинги, новости, аналитика.
Первая базовая единица — **депозиты**. Дальше: карты (дебетовые/кредитные), кредиты, пакеты услуг, платёжные системы.

## 2. Стек и почему именно он

| Слой | Выбор | Почему |
|---|---|---|
| Язык / фреймворк | **PHP 8.3 + Laravel 13** | BrainyCP — LAMP-панель: PHP+Apache/nginx+MySQL есть «из коробки», ничего экзотического на сервер ставить не нужно. Laravel даёт миграции, ORM, авторизацию, очереди, планировщик, кеш. |
| БД | **MySQL 8 / MariaDB 10.6+** (BrainyCP), SQLite — для разработки и тестов | Подключение настраивается в мастере установки через интерфейс. |
| Шаблоны | **Blade (SSR)** | Финансовый портал живёт поиском: страницы должны отдаваться готовым HTML, а не пустым JS-приложением. |
| Фронтенд | **Vite + Tailwind CSS 4 + Alpine.js**, точечно GSAP/ECharts | Сборка на ноутбуке/CI, на сервер едут готовые файлы `public/build`. Интерактив — «острова» на Alpine без тяжёлого SPA. |
| Excel | **PhpSpreadsheet** | Импорт xlsx/xls/csv в админке. |
| Шрифты | Unbounded (заголовки), Manrope (текст), JetBrains Mono (цифры) | Кириллица + казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і). |

Требования к серверу: PHP ≥ 8.3 с `pdo_mysql, mbstring, intl, zip, gd, xml, fileinfo`; document root сайта → `/home/tsoy/sites/banqofbank/public`.

## 3. Архитектура

```
Браузер ──► nginx/Apache (BrainyCP) ──► public/index.php ──► Laravel
                                                    │
     ┌──────────────── Middleware EnsureInstalled ──┤ (нет storage/installed → /install)
     │                                              │
  /install  (мастер)        /  (витрина)        /admin  (админка)
     │                          │                   │
     ▼                          ▼                   ▼
 InstallerService        Public контроллеры    Admin контроллеры
  · проверка окружения    · Dashboard           · Settings
  · тест БД, запись .env  · Banks / Deposits    · Banks / Deposits
  · миграции + админ      · Ratings / News      · Import Excel
                                  │                   │
                                  └──── Models (Eloquent) ────► MySQL
                                        Settings (кеш)
```

Принципы:
- **Модули по доменам** (`Banks`, `Deposits`, `Ratings`, `News`, `Settings`, `Installer`, `Import`) — каждый новый продукт (карты, кредиты) добавляется тем же шаблоном.
- **Настройки сайта — в БД** (таблица `settings`, ключ→значение, кеш), а не в коде.
- **История ставок не теряется**: ставка — это отдельная запись с датой, а не поле, которое перезаписывается. Отсюда графики «как менялась ставка».
- **Всё денежное — в `decimal`**, ставки — `decimal(6,3)`.

## 4. Модель данных (этап 1)

### Ядро
- `settings` — key, value (json), group. Название, слоган, описание, логотип, фавикон, подвал, копирайт, **год основания проекта** (годы жизни считаются автоматически: «2026–2027»), соцсети, метрики.
- `users` — + `role` (admin / editor / user).

### Банки
- `banks` — slug, code (BCC, FFIN…), **aliases** (как банк пишут в Excel: Halyk, Forte, Homecredit…), name, name_kz, short_name, legal_name, bin, license, logo, brand_color, website, phone, swift, founded_year, is_kdif_member (член КФГД), status, sort.

### Депозиты
- `deposit_products` — bank_id, slug, name, **type**, currency(ies), min_amount, max_amount, term_min/term_max (мес.), capitalization, early_withdrawal, online_opening, description, conditions (json), source_url, is_active.
- `deposit_rates` — product_id, currency, term_months, amount_from/amount_to, **rate** (номинальная), **effective_rate** (ГЭСВ), valid_from, valid_to, source (manual / import / parser), import_id.
- `imports` — файл, кто загрузил, когда, сколько строк создано/обновлено/с ошибками, лог.

**Типы вкладов** — по классификации Казахстана (КФГД), и они совпадают с колонками твоего Excel:

| Колонка в Excel | Тип в системе | Что можно |
|---|---|---|
| Снятие и пополнение | `demand` (несрочный) | пополнять и снимать |
| Пополнение | `term` (срочный) | только пополнять |
| Табу | `savings` (сберегательный) | ни пополнять, ни снимать |

### Рейтинги (этап 3)
- `ratings` — bank_id/product_id, kind (`author` — мой, `objective` — расчётный, `people` — народный), score, period.
- `reviews` — user_id, bank_id, product_id, score 1–5, title, text, status (модерация), likes, ответ банка.

### Новости (этап 3)
- `news` — slug, title, lead, body, cover, bank_ids (теги), published_at, source.

### Платёжные системы (этап 4)
- `payment_systems` (Visa, Mastercard, UnionPay, Мир, Элкарт…), `payment_system_products` (уровни карт, привилегии).

## 5. Импорт Excel

Твой `deposits.xlsx` — матрица «банк × тип вклада». Основной лист «Лист2»: 13 банков, над каждым типом объединены две ячейки — **номинальная ставка и ГЭСВ** (формат `0.00%`). Листы «Sheet1» и «Лист1» — черновики (одна ставка FFIN 16,35 %, которая расходится с «Лист2»: 14,46 %).

Импортёр:
1. Принимает `.xlsx/.xls/.csv/.ods`, сам определяет ориентацию (банки в строках или в столбцах).
2. Понимает объединённый заголовок «ставка + ГЭСВ».
3. Процентный формат ячейки (0,142 → 14,2 %) переводит сам; «15,5%» текстом тоже понимает.
4. Находит банк по коду, имени или **алиасу** (Halyk → Halyk Bank, Homecredit → Home Credit, Altyn-i → Altyn Bank). Незнакомые (в твоём файле это Alatau; Bereke, Nurbank, VTB пока пустые) показывает и предлагает создать.
5. Нули и пустые ячейки = «нет данных», а не «ставка 0 %».
6. Показывает **предпросмотр** с выбором листов, затем пишет `deposit_rates` с `source=import`. Повторный импорт того же файла ничего не дублирует; изменившаяся ставка закрывает старую — история сохраняется.

Чего в файле пока нет и что стоит добавить: **срок** (3/6/12/24 мес.), **валюта** (KZT/USD), **минимальная сумма**, **название продукта**. Импортёр уже понимает эти колонки в «плоском» формате (`Банк | Тип | Срок | Валюта | Ставка | ГЭСВ`).

## 6. Фронтенд и дизайн

Дизайн-язык «2126»: тёмная тема по умолчанию + светлая, глубокий космический фон, жидкие градиенты (aurora/mesh), стекло (glassmorphism) с тонкой подсветкой граней, живые числа (count-up), мягкий параллакс, микроанимации на ховерах, уважение к `prefers-reduced-motion`.

Токены: `--bg`, `--surface`, `--glass`, `--text`, `--muted`, `--accent-1..4` (циан → фиолет → маджента → янтарь), `--radius`, `--blur`. Все цвета — переменные, темы переключаются атрибутом `data-theme`.

Страницы витрины:
1. **Главная-дашборд**: «пульс рынка» (макс. ставка по каждому типу, базовая ставка НБРК, инфляция), топ-вкладов, движение ставок, лента новостей, народный рейтинг, быстрый калькулятор.
2. **Депозиты**: каталог с фильтрами (тип, валюта, срок, сумма, банк), сортировка, сравнение до 4 вкладов, калькулятор дохода с капитализацией.
3. **Банк**: карточка, все продукты, история ставок, отзывы, рейтинги.
4. **Рейтинги**: три вида рейтингов рядом.
5. **Новости**, **Платёжные системы**, **Аналитика**.

Админка: тот же визуальный язык, но спокойнее; боковое меню; формы с живым предпросмотром (логотип, фавикон, подвал).

## 8. Деплой на BrainyCP

1. В BrainyCP: сайт → document root `/home/tsoy/sites/banqofbank/public`, PHP 8.3, создать БД и пользователя.
2. На сервере: `git clone` (или `git pull`) в `/home/tsoy/sites/banqofbank`, `composer install --no-dev -o`. Собранный фронтенд (`public/build`) лежит в репозитории, Node на сервере не нужен.
3. Права: `storage/` и `bootstrap/cache/` — запись для пользователя PHP.
4. Открыть сайт → мастер установки сам проверит окружение, подключится к БД, создаст таблицы и админа.
5. Cron: `* * * * * php /home/tsoy/sites/banqofbank/artisan schedule:run`.

Скрипт `deploy.sh` в корне делает шаги 2–3.
