# Журнал действий

> Каждый шаг — номер `A..`, дата, что сделано и зачем. Новые записи — в конец. Тот же номер ставится в комментарии к коду, который этот шаг создал.

## 2026-11-26 · Этап 0, каркас (PR #1)

- **A01 — Выбор стека.** PHP 8.3 + Laravel 13, MySQL/MariaDB, Blade SSR + Vite + Tailwind 4 + Alpine.js, PhpSpreadsheet. Причина: BrainyCP — классическая LAMP-панель; SSR нужен для поиска. План — `docs/PLAN.md`. Конфиг проекта — `config/banq.php`.
- **A02 — Карта маршрутов** `routes/web.php`: витрина, вход, мастер установки, админка.
- **A03 — Мастер установки.** Глобальный middleware `EnsureInstalled` (сам создаёт `.env` и `APP_KEY`), 3 шага: проверка окружения → БД через форму (тест подключения, запись `.env`, миграции) → сайт и администратор. Признак установки — `storage/app/installed.json`; после установки `/install` отвечает 404.
- **A04 — Дизайн-система «2126».** Тёмная/светлая темы на CSS-переменных, живой фон (ауры, сетка, зерно), стекло с подсветкой граней за курсором, градиентный текст, анимированные счётчики, появление блоков, бегущая строка. `prefers-reduced-motion` отключает движение.
- **A05 — Настройки сайта** в таблице `settings` с кешем: название, слоган, описание, логотип, фавикон, подвал, копирайт, год рождения → «годы жизни проекта», email, счётчики, тема. Админка с живым предпросмотром.
- **A06 — Справочник банков** `banks` + сидер на 18 банков РК с кодами и алиасами (черновик, сверить с АРРФР).
- **A07 — Модель депозитов.** `deposit_products` (тип КФГД: несрочный/срочный/сберегательный) и `deposit_rates` с историей (valid_from / valid_to), номинальная ставка + ГЭСВ.
- **A08 — Импорт Excel.** Парсер понимает «матрицу» в любой ориентации, объединённые заголовки «ставка + ГЭСВ», процентный формат, «плоскую» таблицу; предпросмотр с выбором листов; повторный импорт без дублей; новая ставка закрывает старую. Проверено на `deposits.xlsx` пользователя (27 ставок с «Лист2»).
- **A09 — Админка:** вход с ограничением попыток, роли admin/editor, обзор, банки, импорт, настройки.
- **A10 — Главная-дашборд:** герой с лучшей ставкой, пульс рынка по типам вкладов, топ ставок, калькулятор дохода с капитализацией, анонсы будущих разделов.
- **A11 — Деплой и CI:** `deploy.sh` для BrainyCP, GitHub Actions (тесты + сборка фронта), собранный `public/build` в репозитории.
- **A12 — Документация:** `docs/PLAN.md`, `docs/REGISTRY.md` (дерево, граф, таблицы, переменные, маршруты), этот журнал, `CLAUDE.md` с правилами для следующих сессий.

## 2026-11-26 · Дизайн v2 по референсам пользователя (PR #2)

- **A13 — Дизайн-система v2 «Bento».** Первый вариант (тёмный неон) пользователю не зашёл. Новый собран по его референсам: vibecoding.ru (светлые белые карточки на сером фоне, три колонки, пилюли навигации, тёмная лента сверху), ui.shadcn.com (нейтральная тёмная тема, pill-кнопки, формы на плашках), бенто-сетки с крупными цифрами, фирменный градиент tsoy.in (фиолет → циан). Шрифт Onest. Светлая тема по умолчанию, тёмная — в стиле shadcn. Новые: `App\Support\Market` (срез рынка для главной и бегущей строки), `partials/icon` (линейные иконки), классы `.card .card-ink .card-soft .card-brand .plate .pill .icon-tile .list-row .meter .range .topline`. Старые классы (`.glass`, `.btn`, `.chip`, `.input`…) сохранены, админка и мастер установки перекрашены автоматически.
