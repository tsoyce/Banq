## 2026-11-26 · Этап 1, витрина вкладов (PR #4)

- **A14 — Каталог вкладов, карточка, сравнение.** Маршруты `/deposits`, `/deposits/{slug}`, `/deposits/compare`. Сервис `App\Services\Deposits\DepositCatalog`: подбор по типу, валюте, сроку, сумме, банку, условиям (пополнение/снятие/онлайн) и поиску; для каждого вклада выбирается лучшая действующая ставка под условия (ставка без срока/порога суммы подходит под любые — так приходят данные из Excel). Сортировка по ставке, ГЭСВ, доходу, банку. Фильтры живут в URL (ссылкой можно поделиться, видят поисковики); с JS список обновляется без перезагрузки — fetch с заголовком `X-Partial: results`. Карточка: бенто со ставкой, ГЭСВ и гарантией КФГД, сетка ставок «сумма × срок», график истории ставки (из закрытых записей `valid_to`), условия, калькулятор, другие вклады банка, похожие вклады. Сравнение до 4 вкладов: список в `$store.compare` (localStorage) + плавающая панель, таблица с подсветкой лучшего в каждой строке и доходом под выбранные сумму и срок. Доход считается по ГЭСВ (уже учитывает капитализацию), иначе по номиналу с ежемесячной капитализацией — одна формула в `Income.php` и `app.js`. Главная: форма «Хочу вклад…» ведёт в каталог, строки топа — в карточки. Хелпер `plural()`, лимиты КФГД в `config/banq.php`: сберегательные в тенге — 20 млн, срочные и несрочные в тенге — 10 млн, в валюте — 5 млн (сверено с kdif.kz 26.11.2026; новый закон о банках от 16.01.2026 лимиты не меняет). Тесты: `tests/Feature/DepositCatalogTest.php`.

## 2026-11-26 · Этап 3 (часть), банки и рейтинги

- **A18 — Страницы банков и три рейтинга.** Каталог `/banks` (лидер объективного рейтинга в чёрной карточке, поиск по имени/коду/алиасу, сортировка: рейтинг, народный, ставка, алфавит; карточка банка с ячейками «ставка до · рейтинг · народный») и страница банка `/banks/{slug}` (о банке, лучшая ставка, три гейджа рейтингов с местом и ▲▼, все вклады банка, разбор объективного рейтинга по критериям, вывод редакции с плюсами/минусами, отзывы с распределением 5…1, форма отзыва, справка «О банке»). Страница `/ratings`: баннер народного рейтинга, лидеры трёх видов, сводная таблица с сортировкой по виду (на мобильном — карточки-строки), методика, свежие отзывы.
  - **Авторский** — ставит админ в `/admin/ratings` (0–5, вывод, плюсы, минусы); хранится по дням, правка в другой день — новая запись, отсюда ▲▼.
  - **Объективный** — `App\Services\Ratings\ObjectiveRating`: ставки к рынку по каждому типу вклада (40 %), надёжность — КФГД, активы в лог-шкале, возраст (30 %), линейка типов (15 %), удобство — онлайн-открытие и вклад со снятием (15 %). Веса — `config/banq.php → ratings.objective_weights`. Нет данных об активах/годе — эти части не штрафуют. Банк без ставок в рейтинг не попадает. Для активов, капитала, года и лицензии добавлены поля в `banks` (правятся на странице оценки в админке).
  - **Народный** — `PeopleRating`: только одобренные отзывы, байесовское среднее (5 «виртуальных» оценок 3,5), чтобы один отзыв «5» не обгонял сотню «4,6».
  - Отзывы: регистрация посетителей `/register` (роль user), один отзыв на банк (повторная отправка = правка, снова на модерацию), «полезно» — один голос, свой отзыв не голосуется; модерация в `/admin/reviews` (опубликовать, отклонить с причиной — автор её видит, ответ банка, удалить), счётчик очереди в меню админки. Вход возвращает посетителя туда, откуда он пришёл (`/login?to=…`, только относительные пути); сотрудников — в админку.
  - Снимок объективного и народного рейтинга — `php artisan banq:ratings-snapshot`, по расписанию в 03:10 (нужен cron `schedule:run`, он уже в инструкции деплоя) и кнопкой в админке.
  - Дизайн: внедрены пункты §13 гайда — `.kicker`, `.num-hero`, `.num-card`, `.cells`, `.delta-up/-down`, токены `--s-author/--s-objective/--s-people`, хелпер `money_format()`; новые `partials/gauge` (гейдж 270°), `partials/stars`, `partials/delta`. Шапка: пилюли «Банки» и «Рейтинги», кнопка «Войти»; на главной анонс «скоро» заменён живым блоком рейтинга. Проверено в светлой/тёмной теме и на 375 px.
  - Тесты: `tests/Feature/BankRatingTest.php` (9 тестов).

## 2026-11-26 · Первый деплой на bank.tsoy.in

- **A19 — `deploy.sh` под BrainyCP с chroot.** Проект впервые развёрнут на сервере (bank.tsoy.in, `/home/tsoy/sites/banqofbank`; заглушка панели — в `/home/tsoy/banqofbank-placeholder-backup`). Выяснилось: PHP-FPM сайта работает в chroot `/home/tsoy` (сайт видит пути как `/sites/...`), поэтому `config:cache`/`view:cache` из консоли записали бы пути, которых сайт не найдёт. Теперь `deploy.sh` по умолчанию только очищает кеши (`optimize:clear`), кеширование включается `ARTISAN_CACHE=1` на серверах без chroot. PHP ищется сам (`php` в PATH, `/usr/bin/php83/bin/php`, `/usr/bin/php84/bin/php`), composer запускается через тот же PHP. В мастере установки хост БД — `127.0.0.1` (в chroot нет сокета MySQL). Корень сайта, версия PHP и SSL меняются только в панели BrainyCP: она перезаписывает ручные правки конфигов.

- **A20 — MySQL на BrainyCP: ключи и движок.** Мастер установки упал на `password_reset_tokens`: «Specified key was too long; max key length is 1000 bytes» — MySQL сервера по умолчанию создаёт таблицы в MyISAM. Теперь соединения mysql/mariadb всегда создают таблицы в InnoDB (`DB_ENGINE`, по умолчанию `InnoDB`), а `Schema::defaultStringLength(191)` держит индексы по строкам в пределах лимита даже на старых серверах.

## 2026-11-27 · Личный кабинет и профиль автора

- **A28 — Личный кабинет, публичный профиль, избранное, сохранённые сравнения.** Пользователь не нашёл «карточки профиля» — теперь они есть.
  - **Кабинет `/account`** (меню-аватар в шапке): шапка с фото, именем, `@адресом`, городом и ступенью автора; чёрная карточка — «ваш голос в народном рейтинге» (опубликованные отзывы, «полезно», сколько до следующей ступени). Вкладки: обзор (счётчики, последние отзывы, «профиль заполнен на N %», избранное, сравнения), мои отзывы (фильтр по статусу, причина отказа, ответ банка, банки без вашего отзыва), избранное (вклады строками каталога с текущей ставкой + «сравнить разом», банки с ставкой и двумя рейтингами), сравнения, настройки.
  - **Настройки:** имя, адрес профиля `/u/{username}` (латиница, служебные слова запрещены), фото до 2 МБ (`public/uploads/avatars`, превью до сохранения), город, страна (ISO-2, `App\Support\Countries` — не FK, справочник стран делает другой модуль), «о себе», публичность; смена почты и пароля с текущим паролем (другие устройства выходят); уведомления (решение модератора, ответ банка, ставки в избранном); удаление аккаунта (кроме админа).
  - **Публичная карточка автора `/u/{username}`:** фото, город, «на портале с…», ступень (Читатель → Первый отзыв → Автор → Знаток → Эксперт), отзывы/банки/«полезно», средняя оценка и распределение 5…1, лента опубликованных отзывов. Имя и аватар у каждого отзыва ведут сюда. Скрытый профиль — 404 для всех, кроме владельца и сотрудников.
  - **Избранное:** кнопка-сердце у вклада в каталоге, на карточке вклада и на странице банка; переключается fetch'ем без перезагрузки, без JS — формой; гостя ведёт на вход.
  - **Сохранённые сравнения:** кнопка «Сохранить» на `/deposits/compare` запоминает набор вкладов с суммой и сроком; в кабинете — открыть, переименовать, удалить.
  - **Письма автору** (`ReviewModerated`): опубликован / отклонён с причиной / ответ банка — если включено; сбой почты не ломает модерацию. Нужен SMTP в `.env` (`MAIL_*`), по умолчанию `MAIL_MAILER=log`. «Ставки в избранном» — настройка уже хранится, рассылка — следующим шагом вместе с уведомлениями этапа 5.
  - После регистрации и входа посетитель попадает в кабинет (если не пришёл с другой страницы). Всплывающее сообщение `.toast` после действий на витрине.
  - Данные: миграция `2026_11_27_002800_create_profile_tables` — поля `users`, таблицы `favorites`, `saved_comparisons`; существующим пользователям адрес профиля проставляется из имени.
  - Тесты: `tests/Feature/ProfileTest.php`.
